### hey I'm june

**I build machine-driven checks that catch what manual code review can't. You need large amounts of complex code integrated safely and quickly, and I make that possible.**

I'm june, a PhD student advised by <a href="https://cs-people.bu.edu/gaboardi/">Marco Gaboardi</a> and working with <a href="https://ankushdas.github.io/">Ankush Das</a> at Boston University. **I defend my thesis in January 2027, and am currently looking for employment starting March 2027**. My PhD has been focused on programming languages and type systems, applied to:

- event driven systems
- reactive programs
- web development
- concurrency/highly multithreaded programs

want to get in contact? my email is june@junewunder.com and I am on <a href="https://bsky.app/profile/junewunder.com">bluesky</a> and <a href="https://mathstodon.xyz/@junewunder">mathstodon.xyz</a>

During my PhD I designed Willow, a type system for functional reactive programming that provides guarantees on temporal behavior. Willow captures the chain of events that may be caused by a state change or event firing.

In addition I also worked with Stefan Muller and Arthur Azevedo de Amorim on GML, a language that can find common runtime-bugs in highly multithreaded programs.

### projects

- **[wfactory](https://github.com/junewunder/wfactory)** helps you set up your own code factory with my sensibilities. A factory is a backlog of similar work that agents work through unattended, where checks that you trust decide when each piece is done.
- **[gbaa](https://github.com/junewunder/gbaa)** turns Game Boy Advance games into Rust. Claude agents wrote the code, guided by wfactory, and the results are checked against the mGBA emulator.
- **[bendcam](https://github.com/junewunder/bending-cam-public)** is a digital camera I designed and built to be glitched on purpose: circuit board, firmware and phone app.
